# Traffic Source Exploration

## Objective

Prepare a clean event-level dataset for marketing analysis.

## Query

sql/01_dataset_preparation.sql

## Business Insights

The extracted dataset contains:

- User identifier
- Session identifier
- Marketing source
- Marketing medium
- Campaign
- Device category
- Country
- Event name

This dataset serves as the foundation for all subsequent marketing analyses.

It enables:

- Funnel Analysis
- User Segmentation
- Device Performance Analysis
- Country Performance Analysis
- Campaign Effectiveness
