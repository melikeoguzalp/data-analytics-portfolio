# Marketing Performance Analytics

## Overview

This project demonstrates an end-to-end marketing analytics workflow using PostgreSQL, Google BigQuery, Google Analytics 4 (GA4), and Looker Studio.

The objective was to analyze advertising performance, prepare analytical datasets from raw GA4 event data, measure user behavior throughout the conversion funnel, evaluate landing page performance, and build business-ready reports for visualization.

The project simulates real-world marketing analytics tasks commonly performed by Data Analysts and Analytics Engineers, covering data extraction, transformation, KPI calculation, funnel analysis, and dashboard development.

---

## Objectives

- Analyze Google Ads and Facebook Ads campaign performance
- Prepare BI-ready datasets from raw GA4 event-level data
- Build marketing funnel metrics from user sessions
- Compare landing page conversion performance
- Analyze the relationship between user engagement and purchases
- Create datasets suitable for business intelligence reporting
